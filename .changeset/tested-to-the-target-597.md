`textLinkVariants` (`@krizaka/ui/button`) styles a discreet link — accent colour, underline on hover and focus, no box — so a site can choose a link where `buttonVariants` would draw a button. Behaviour tests for `VerifiedBadge`, `StepProgress` and `DescriptionList`, and a guard (`coverage-guard.test.ts`) that fails when an exported component has no story, no unit test or no Linux baseline, outside a list of exceptions that only goes down.
