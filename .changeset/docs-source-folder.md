`@krizaka/ui/docs-source`: `docsSource(files, { locale })` turns a folder of `<page>.<locale>.md` into the page list, the `DocsNav` groups, the headings for `Toc` and the previous / next of `DocsArticlePage`, with the heading ids `Markdown` gives; `@krizaka/ui/docs-source/node` reads the folder (`readDocsFolder`). Pure, no network, no Fumadocs in its API.
