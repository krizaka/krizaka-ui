Reduction, batch 1 (ADR-006 §7, krizaka-ui#674): 28 entries with no user and no filed need are deprecated in 3.55 and removed in 4.0; nothing is removed in this minor. Each carries `@deprecated` JSDoc, `status: "deprecated"` in its `meta.ts` (ui.krizaka.com shows the badge and sinks it in the catalogue), and a development-only console warning, once per page and never in production (`warnDeprecated`). Showcase and effects: `terminal-replay`, `showcase`, `retro-tv`, `scroll-stage`, `landscape`, `signature`, `anatomy-plate`, `elephant` (`pointer-light` was already deprecated in 3.31). Data views: `kanban` (`tree-view` was already deprecated in 3.6). Engagement: `continue-prompt`, `promise-card`, `swipe-deck`, `match-dialog`. Web media editors: `media-capture` (web and native), `video-trimmer`, `image-cropper`. Web lifecycle screens: `update-prompt`, `force-update-screen`, `maintenance-screen` (the native twins stay). Page templates no page uses: `product-page`, `gallery-page`, `component-page`, `status-page`. Native entries no app imports: `native/vertical-video` and `native/markdown` (their web entries stay), `native/media-capture`. On watch, not deprecated: `pricing-page`, `contact-page`, `docs-layout`. A product that objects comments on krizaka-ui#674 with its issue and the entry goes back to « keep ». A test lists the deprecated entries, so a kept component, a registry example or the documentation site cannot import one.
