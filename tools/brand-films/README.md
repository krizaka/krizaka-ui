# Brand films — the Krizaka flock, filmed from the code

The mascots are our signature. These films are rendered from the **real components** of `@krizaka/ui` — `Mascot`,
`Landscape`, `KrizakaLogo` — never redrawn, never generated by a model: a bird or a mark that changes in the package
changes in the films at the next render.

| What | Where it is used |
| :--- | :--- |
| **One loop per bird** (8 s, seamless): idle life (breathe, blink, ruffle) + its promise as a gesture | ui.krizaka.com's brand page; a product's page where its bird appears |
| **« Le monde de Krizaka »** (44 s, 16:9 and 9:16): the flock on krizaka.com's hero scene, each bird stepping forward with its promise, the end on the Krizaka mark | krizaka.com `/story` (site cut, captions as WebVTT), social cuts (captions burned in, EN and FR) |

## Render

```bash
pnpm install --frozen-lockfile
pnpm turbo run build --filter=@krizaka/ui        # the stages read the built package, like tools/export-brand.mjs

# Look first: a few stills of every loop and of the film (seconds, no lock needed)
node tools/brand-films/render.mjs --out /tmp/films --only stills

# Everything (heavy: take the Mac's heavy-task lock first)
node tools/brand-films/render.mjs --out /tmp/films --music /tmp/films/bed.wav
node tools/brand-films/render.mjs --out /tmp/films --only loops --birds owl,duck   # some loops only
```

Needs ffmpeg (libx264, libvpx-vp9, libopus) and Playwright's Chromium (the version `apps/storybook` pins). Each stage is
opened in a headless Chromium, every CSS animation is paused and set to the exact time of each frame: no dropped frame,
the same pixels at every render, and a loop's frame at 8 s is checked against its frame at 0 s (PSNR ≥ 45 dB) — a track
that does not close fails the render.

Outputs (the names krizaka-com keeps on Bunny, hashed, under `site/brand-films/`):

```
loops/<bird>-{square,vertical}-{dark,light}.{mp4,webm,jpg}   1080², 1080×1920 — the poster is the promise kept
loops/<bird>-alpha.{webm,png}                                 transparent VP9 (720²), mid-tone outline: reads on both themes
film/le-monde-de-krizaka-{16x9,9x16}.{mp4,webm,jpg}          site cut: no burned captions, music
film/le-monde-de-krizaka-{16x9,9x16}-{en,fr}.mp4              social cuts: captions burned in
film/le-monde-de-krizaka-{en,fr}.vtt · film/cues.json         the captions
render-report.json                                            the @krizaka/ui version, timings, sizes
```

Then, from krizaka-com (it owns the `site/` prefix and its manifest):

```bash
node scripts/cdn-assets.mjs upload <out>/loops --to brand-films/loops --env-file <bunny env>
node scripts/cdn-assets.mjs upload <out>/film  --to brand-films/film  --env-file <bunny env>
node scripts/cdn-assets.mjs prune  --env-file <bunny env>   # then --yes: the superseded versions go (replace, never accumulate)
```

## Music

The bed is generated by **ACE-Step 1.5 XL turbo** (MIT) through **Orazaka's media worker** (`orazaka-worker-media`,
`app/sound_generators.generate_music`, the model pinned in its `models.yaml`), on the Mac (Metal, ~40 s, $0):

```bash
cd orazaka-apps/workers/orazaka-worker-media
.venv/bin/python -c "import sys; from app.sound_generators import sound_models, generate_music; \
  print(generate_music(sound_models()['acestep-v15-xl-turbo'], sys.argv[1], 44, sys.argv[2], seed=20261016))" \
  "$(node -e "import('<krizaka-ui>/tools/brand-films/film.mjs').then(m => process.stdout.write(m.FILM.music.prompt))")" /tmp/films/bed.wav
```

The prompt, the seed and the fades are in `film.mjs` (`FILM.music`). Credit: *Music: ACE-Step 1.5 (MIT), generated with
Orazaka.* The loops have no sound.

## Change a film

- **A mark or a bird changed** in `@krizaka/ui`: release, build, render again, upload, prune. Nothing else.
- **A gesture**: `choreography.mjs` — tracks of `[seconds, "css", easing]` on the parts the component names
  (`.kzb-bird`, `.kzb-wing`, `.kzb-wing-r`, `.kzb-eye`) and on the props; idle life uses `scale`/`rotate`/`translate`,
  gestures use `transform`, so they compose. A loop track is closed on its first stop by the builder.
- **The film**: `film.mjs` — the moments (`FILM.spotlight`), the places per aspect (`layout`), the captions (`FILM.cues`;
  krizaka.com renders its own WebVTT from its messages, keep the words and the times in step).
- A new bird of the flock fails `brand-films.test.mjs` until it has its loop.

**Shared choreography with krizaka.com's hero intro (WWW-HERO)**: the mark draws its shield (`pathLength="1"`,
`stroke-dashoffset` 1 → 0 over ~1.4 s, ease in-out), the birds hop up to their places (`OUT` then `FALL`, 70–320 ms
staggered), a light sweeps across the valley (105°, 2 s). Use the same easings (`EASE`, `OUT`, `POP`, `FALL` in
`choreography.mjs`) so the site's intro and the films move alike.
