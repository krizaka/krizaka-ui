# @krizaka/icons — Package Contract (agent-neutral)

> Published on npm as **`@krizaka/icons`**. Lives in `packages/icons` of the krizaka-ui monorepo: the root
> [`AGENTS.md`](../../AGENTS.md) applies first. The brand system is [`../tokens/BRAND.md`](../tokens/BRAND.md).

## 1. What belongs here

- The **Krizaka signature icons** (level 1 — no product word in a component, a glyph is a shape): React and React
  Native, one named export per icon (`<Name>Icon`), the same names on both platforms.
- Not here: brand marks (`@krizaka/ui`), illustrations, product compositions.

## 2. Rules

- **The source is `scripts/glyphs.mjs`.** `src/glyphs.ts`, `src/icons.ts`, `src/native/icons.ts` are generated by
  `pnpm glyphs` and committed; a test regenerates and compares them.
- **The grammar** (README, "Style"): 24 grid, coordinates within 1–23, stroke 1.75, round caps/joins, cut (45°)
  corners on containers, **one node** on every `product` glyph, none on the utility glyphs. A test checks it.
- **currentColor only** on the web; the node takes `nodeColor`. Native takes `color` / `nodeColor` from the app's
  theme. No hard-coded colour in a glyph.
- **Accessible:** decorative by default (`aria-hidden`), an image with `title` (`role="img"`, `aria-label`, `<title>`).
- **Server-safe:** no hook, no `"use client"`. **Tree-shakable:** every icon is a `/* @__PURE__ */` call, `sideEffects:
  false`; never a namespace re-export (`export * as`) — it defeats tree-shaking.
- Dependencies: none. Peers: `react` ≥ 18, `react-native-svg` ≥ 15 (optional, for `./native`).

## 3. Quality gates

- `pnpm turbo run check --filter=@krizaka/icons`: ESLint + `tsc`, tests (Vitest + happy-dom: the set, the grammar,
  the props, the generated files, the native icons against a mocked react-native-svg), build (tsup), size, publint +
  attw (`esm-only`). Stories (`src/**/*.stories.tsx`) are rendered, audited and screenshot-compared by `apps/storybook`.
- **Size budgets** (gzip, peers excluded): one icon ≤ 1 kB, `.` ≤ 5 kB, `./native` ≤ 5 kB.
- Published surface: exports `.`, `./native`, `./glyphs`, `./package.json`; files `dist`, `README.md`, `LICENSE`.
  Removing or renaming an icon or a prop is a breaking change; a new icon is a minor; a redrawn icon is a minor.

## 4. Release

A changeset for every change to `scripts/glyphs.mjs` or `src/`. `@krizaka/icons` is **not** in the `fixed` group: it
versions on its own (0.x while the products adopt it).
